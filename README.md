## Описание проекта

Репозиторий содержит практические работы по дисциплине «Технологии индустриального программирования». Работы посвящены основам JavaScript, организации кода, созданию интерактивных приложений и взаимодействию с HTTP API.

## Практические работы

### Практическая работа №1 — Основы JavaScript
Изучение базового синтаксиса JavaScript, переменных, типов данных, условий, циклов и отладки программ.

[Перейти к Practice-01](./practice-01/README.md)

### Практическая работа №2 — Функции и модули
Работа с функциями, разделение логики на модули и проверка корректности работы программы.

[Перейти к Practice-02](./practice-02/README.md)

### Практическая работа №3 — Интерактивное приложение
Создание интерфейса для работы со списком задач, добавление и удаление записей, фильтрация данных.

[Перейти к Practice-03](./practice-03/README.md)

### Практическая работа №4 — Формы и хранение данных
Реализация формы добавления и редактирования задач, валидация пользовательского ввода, фильтрация и сохранение данных в `localStorage`.

[Перейти к Practice-04](./practice-04/README.md)

### Практическая работа №5 — Асинхронность и HTTP API
Использование `Promise`, `async/await`, `fetch`, обработка HTTP-ошибок и получение данных с локального API.

[Перейти к Practice-05](./practice-05/README.md)

## Используемые технологии

- Git и GitHub

## Запуск проектов

Для запуска отдельных практических работ следуйте инструкциям в соответствующих файлах `README.md`.

Для работ, использующих Node.js, предварительно установите Node.js и проверьте его доступность:

```bash

```
