### Цель
Разделить модель данных, функции для работы с задачами и сценарий запуска на ES-модули.

### Запуск
Из корня репозитория:
```bash
node practice-02/examples/functions-and-references.js
node practice-02/src/main.js
node practice-02/checks.js
```
Или из папки `practice-02`: `npm start`, `npm run examples`, `npm run check`.

### Реализовано
Создание задачи с проверкой полей, поиск по идентификатору, добавление, удаление, переключение статуса, фильтрация и расчёт статистики. Функции возвращают новый массив при изменении данных и не используют DOM.

### Вывод
Модули помогают отделить данные и бизнес-логику от вывода. Проверка входных значений позволяет возвращать понятный результат ошибки, не повреждая текущий список.

### Результаты проверки
Указать фактический результат запуска `node checks.js`.
