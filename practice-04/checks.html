ПР4 — проверочный список

Автоматические проверки сервиса запускаются из папки practice-04 командой npm run check.

  1. Добавить задачу с корректным ID и названием.
  2. Попробовать повторить существующий ID и отправить пустое название.
  3. Отредактировать задачу и проверить, что ID не меняется.
  4. Изменить статус, применить все три фильтра и удалить задачу.
  5. Перезагрузить страницу и проверить сохранение в localStorage.
  6. Нажать «Сбросить данные» и убедиться, что исходный список восстановлен.
