### Цель
Научиться проверять данные формы, создавать и редактировать задачи и сохранять их в `localStorage`.

### Реализовано
- создание и редактирование задач в одной форме;
- проверка ID, названия и приоритета;
- фильтрация, изменение статуса и удаление;
- сохранение списка в JSON и восстановление после перезагрузки;
- сброс сохранённых данных к демонстрационному набору;
- отдельный ключ для набора варианта.

### Запуск
Из этой папки:
```bash
npm start
```
Откройте `http://127.0.0.1:5504`. Проверки сервиса: `npm run check`.

### Что проверить вручную
1. Добавить задачу, перезагрузить страницу и убедиться, что она осталась.
2. Отредактировать название и приоритет.
3. Попробовать пустое название и повторный ID.
4. Изменить статус, удалить задачу и проверить фильтры.
5. Нажать «Сбросить данные» и проверить исходный набор.

### Вывод
HTML-валидация помогает на уровне формы, а прикладная валидация проверяет правила модели. `localStorage` хранит строку, поэтому данные сериализуются через `JSON.stringify` и читаются через `JSON.parse`.

### Результаты
Заполнить после запуска: версия Node.js, результат `npm run check` и результаты ручных проверок.
