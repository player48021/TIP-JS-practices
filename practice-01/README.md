### Цель
Подготовить окружение и изучить запуск JavaScript, типы данных, преобразования, условия и циклы.

### Структура
- `index.html` — страница для запуска скрипта в браузере.
- `js/hello.js` — запуск и сравнение сред выполнения.
- `js/types.js` — типы и преобразования.
- `js/progress.js` — проверка количества задач и сводка.
- `js/plan.js` — планирование задач по дням.
- `js/debug.js` — пример для отладки.

### Запуск
Из корня репозитория:
```bash
node practice-01/js/hello.js
node practice-01/js/types.js
node practice-01/js/progress.js
node practice-01/js/plan.js
node practice-01/js/debug.js
```
Для запуска в браузере откройте `index.html` и вкладку Console в DevTools.

### Краткие выводы
JavaScript может выполняться в браузере и Node.js. Браузер предоставляет DOM, а обычный запуск через Node.js — нет. При работе со строками и числами важно явно преобразовывать типы и проверять входные значения.

### Результаты проверки
Заполнить после запуска: версия Node.js, вывод команд и наблюдения при отладке.
