# Практическая работа №5
## Асинхронные операции и получение данных с сервера

**Студент:** Войнов Максимилиан Олегович  
**Группа:** ЭФБО-14-25  
**Вариант:** 1

### Цель
Изучить Promise, `async/await`, HTTP-запросы, проверку JSON и обработку сетевых ошибок.

### Реализовано
- локальный учебный HTTP API только для чтения;
- общий клиент `fetch` с тайм-аутом, внешней отменой и типизированными ошибками;
- формирование URL и query-параметров;
- предметный клиент для задач и категорий;
- параллельная загрузка независимых ресурсов через `Promise.all`;
- проверки сервиса, клиента и интеграции.

### Запуск
Требуется Node.js 18+ (в курсе рекомендуется Node.js 24). Из папки `practice-05` откройте два терминала.

Терминал 1:
```bash
npm start
```
Терминал 2:
```bash
npm run example:order
npm run example:fetch
npm run client
npm run check:client
npm run check:integration
```
Проверка сервера выполняется `npm run check:api`. Сервер доступен по адресу `http://127.0.0.1:5505/api`.

### Вывод
`fetch` возвращает Promise с объектом Response. HTTP-статус 404 сам по себе не приводит к отклонению Promise, поэтому необходимо проверять `response.ok`. После этого проверяются тип содержимого и схема JSON. `Promise.all` позволяет ждать независимые запросы совместно.
