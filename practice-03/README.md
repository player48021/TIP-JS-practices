### Цель
Создать интерактивную страницу со списком задач, научиться создавать DOM-элементы, делегировать события и фильтровать данные.

### Запуск
Откройте `index.html` через локальный сервер (например, Live Server в VS Code). В браузере доступны добавление, удаление и переключение статуса задач, а также фильтры «Все», «В работе» и «Выполненные».

### Реализовано
- отображение списка из модели данных;
- фильтрация без удаления скрытых задач из исходного массива;
- делегирование кликов на контейнере списка;
- безопасный вывод названий через `textContent`;
- обновление сводки и пустого состояния.

### Вывод
DOM отвечает за представление данных в браузере. Данные хранятся отдельно от отображения, поэтому после изменения массива интерфейс можно перерисовать. Делегирование позволяет обрабатывать действия карточек одним обработчиком на контейнере.

### Проверки
Проверить все фильтры, переключение статуса, удаление последней записи и возврат к фильтру «Все». Указать фактические результаты после ручного запуска.
