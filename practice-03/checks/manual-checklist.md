# Ручные проверки ПР3

- [ ] Открывается страница без ошибок в Console.
- [ ] Фильтр «Все» показывает все задачи.
- [ ] Фильтр «В работе» показывает только невыполненные задачи.
- [ ] Фильтр «Выполненные» показывает только выполненные задачи.
- [ ] Переключение статуса обновляет карточку и сводку.
- [ ] Удаление задачи обновляет список и сводку.
- [ ] Можно добавить задачу с непустым названием.
- [ ] Пустое название не добавляется благодаря проверке формы.
- [ ] После удаления последней видимой задачи показывается пустое состояние.
- [ ] Название с символами `<` и `>` выводится как текст, а не HTML.
